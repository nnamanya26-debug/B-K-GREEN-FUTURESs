# B&K Green Futures — GitHub Pages

This folder contains a static version of the B&K Green Futures website for GitHub Pages. It includes a homepage and interactive About, Services, Gallery and Contact pages.

To deploy, put `index.html` in the root of the repository's `main` branch and set GitHub Pages to deploy from `main` / `(root)` in the repository's Pages settings. The WordPress PHP theme is a separate package and does not run on GitHub Pages.
